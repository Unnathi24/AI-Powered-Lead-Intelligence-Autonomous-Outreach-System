# Autonomous AI Lead Intelligence & Research Engine

## 🚀 Project Overview
This project is a sophisticated two-stage automation pipeline designed to bridge the gap between cold inbound leads and high-value, researched sales consultations. It leverages AI Agents and advanced web scraping to handle lead qualification, competitive intelligence, and autonomous scheduling.

### 💼 Business Value
- **90% Reduction** in manual lead research time.
- **Hyper-Personalization:** Uses real-time scraped HTML to craft outreach that references a prospect's specific services and niche.
- **24/7 Response:** Immediate engagement ensures leads are captured while they are most interested.

## 🛠️ Tech Stack
- **Orchestration:** [Make.com](https://make.com)
- **Data Extraction:** [Browse.ai](https://browse.ai) (Specialized for JS-heavy/Wix sites)
- **Intelligence:** OpenAI GPT-4o (via Make AI Agents)
- **CRM/Storage:** Google Sheets
- **Communication:** Gmail & Google Calendar

## 🧩 Complex Problems Solved

### 1. The Wix/SPA Rendering Challenge
**Problem:** Standard scrapers often fail on Wix-built sites because the content is rendered via Javascript after the page loads.
**Solution:** Implemented specialized routing logic in Make.com to format and validate URLs for Browse.ai's browser-mimicking engine, bypassing "browser verification" blocks and handling asynchronous rendering.

### 2. Cross-Scenario State Management
**Problem:** Make.com scenarios run independently, making it difficult to pass data from a scraper (Scenario 1) to an AI Agent (Scenario 2) without losing context.
**Solution:** Built a robust "Task ID Sync" using Google Sheets as a middle-ware state manager. Scenario 2 uses a `Search Rows` module to retrieve the correct lead context based on the unique `taskID` generated by Browse.ai.

### 3. High-Signal AI Prompt Engineering
**Problem:** Automated emails often sound robotic and clichéd.
**Solution:** Developed a "Senior Analyst" system prompt that forces the AI to analyze raw HTML for 1-2 specific business details, avoiding cliches like "I hope this email finds you well" and focusing on data-driven research.

## 📂 Repository Structure
- `/blueprints`: Contains `.json` export files of the Make.com scenarios.
- `/prompts`: Contains the specialized System Prompt for the AI Agent.
- `/docs`: High-resolution screenshots of the automation architecture.

## ⚙️ Setup Instructions
1. Import the blueprints from the `/blueprints` folder into your Make.com account.
2. Connect your **Browse.ai**, **Google Sheets**, and **Gmail** accounts to the respective modules.
3. Set up a Webhook in Browse.ai pointing to the Trigger in Scenario 2.
4. Ensure your Google Sheet has columns for `Task ID`, `First Name`, `Email`, and `Website HTML`.
